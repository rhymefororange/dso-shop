# Architecture Decision Records

Значущі архітектурні рішення фіксуються у форматі ADR: один файл на рішення,
ім'я `NNNN-коротка-назва.md` (наприклад, `0001-webhook-authentication.md`).

Структура запису:

```
# ADR-NNNN: <Назва рішення>

Статус: Запропоновано | Прийнято (РРРР-ММ-ДД) | Замінено ADR-NNNN

## Контекст
## Розглянуті варіанти
## Рішення
## Наслідки
```
