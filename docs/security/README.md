# Артефакти безпеки

Каталог для артефактів, що створюються під час лабораторних робіт курсу:
модель загроз (`threatmodel/`), реєстр загроз, вимоги безпеки й матриця трасування,
таблиці triage, пріоритизовані переліки вразливостей, аналіз VEX тощо.

Зміни в цьому каталозі проходять рецензування через pull request.
